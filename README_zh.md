# 户外 PV/T 灰箱建模复现仓库

这是一个面向论文复现的精简仓库，服务于小型水冷光伏/光热（PV/T）集热器的户外瞬变实验数据处理与整日验证。它不是旧竞赛工程的整体搬运。

当前 `0.1.0` 版本只保留经过审计的温度/辐照度数据构建脚本、整日留一日基线模型、自动测试和数据质量记录。九个实验日共 41,599 条记录，包含 300 和 500 mL/min 两种按日设定的流量工况。原始数据暂不随仓库发布，直到数据归属和许可证得到确认。

## 当前能做什么

- 从原始记录重建温度与辐照度数据集；
- 修复记录仪计时器复位导致的时间轴中断；
- 明确保留板温、水箱温度和入口温度三个通道；
- 进行以整日为单位的留一日验证；
- 用 JSON 和 Markdown 保存 QC 与局限性。

## 当前不能声称什么

- 没有出口水温，不能声称实测热功率或热效率；
- 流量是按日设定值，不是连续实测量；
- 三月记录仪没有环境温度和风速；
- 电功率记录尚未完成独立、可复现的时间对齐；
- 旧 HIL、PINN、节水和优化控制结果不属于本仓库首版证据。
